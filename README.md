A tiny program that writes exactly one sentence to
`/output/entry.txt` — the best meal as a single gesture: **Picking
tomatoes still warm from the vine with my mother, then eating one
over the sink, juice running to my elbow, salt from her palm — that
was the whole meal, and it was enough.** No restaurant, no courses,
nothing bolted on: warmth, juice, salt, a mother, and a verdict. It
was chosen by a criteria-ordered tournament against the judge's
published criteria (most concrete, most personal, most worth
remembering), beating a gumbo-after-the-funeral runner-up that was
vivid but heavier. Output is byte-exact with no trailing newline.
Run it with `python3 main.py`.
